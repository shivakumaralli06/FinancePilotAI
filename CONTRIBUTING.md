# Contributing to FinancePilot AI 🚀

Thank you for your interest in contributing to **FinancePilot AI**! We welcome contributions from developers of all skill levels.

---

## 📜 Code of Conduct

Please foster an inclusive, respectful, and welcoming environment for all contributors.

---

## 🛠️ How to Contribute

1. **Fork the Repository**: Click the "Fork" button at the top right of this repository.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/your-username/financepilot-ai.git
   cd financepilot-ai
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-new-feature
   ```
4. **Set Up Development Environment**:
   - Backend: `cd server && npm install`
   - Frontend: `cd client && npm install`
   - Configure `.env` files based on `.env.example` templates.
5. **Make your Changes & Commit**:
   ```bash
   git commit -m "feat: add amazing new feature"
   ```
6. **Push to your Fork**:
   ```bash
   git push origin feature/amazing-new-feature
   ```
7. **Open a Pull Request**: Submit a Pull Request targeting the `main` branch.

---

## 🧪 Testing & Verification

- Ensure backend routes run cleanly (`npm run dev` in `server/`).
- Verify frontend builds without errors (`npm run build` in `client/`).
- Confirm zero secrets or `.env` credential files are staged.
